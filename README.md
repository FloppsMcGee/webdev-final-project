# Yusuf Ahmed Portfolio Website

Final Project:

This is my final project for the Intro to Web Development class. Since I am a big fan of cars, F1, and love the Audi team colors, I decided to theme the website a bit after the Audi F1 theme. The site has an About section, Previous Work section, Projects section, and Contact section.

## How to Run

Open `FinalProject.html` in a web browser or as live server from vscode.

## Concepts Used

- HTML
- CSS
- JavaScript

## Features

- Responsive navigation bar
- Mobile menu toggle
- Project card layout
- Contact form validation
- Smooth scrolling
- Audi F1 inspired visual theme

## Outside Sources Used

- MDN Web Docs: CSS Grid
- MDN Web Docs: `::before` for triple /// design associated with F1 style
- MDN Web Docs: `scroll-behavior` for smooth scrolling when clicking on links
- MDN Web Docs: `addEventListener` for form and mobile/small windwo navigation menu
