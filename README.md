# Yusuf Ahmed Portfolio Website

## Final Project:

This is my final project for the Intro to Web Development class. Since I am a big fan of cars, F1, and love the Audi team colors, I decided to theme the website around the Audi F1 theme and motorsports in general. I designed the website around the team colors using dark greys and red/orange accents.

The website has the typical portfolio items such as background information, prvious work experience, projects, and contact information, as well as links to my LinkedIn and Github at the bottom.

## How to Run

Launch the project using the Live Server extension in VS Code.
Open the Deployed Site: https://floppsmcgee.github.io/webdev-final-project/
